# 🏆 Copa Resultado 2026

Sistema Full Stack para gerenciamento da Copa do Mundo de 2026.

O projeto permite acompanhar as partidas da fase de grupos, consultar a classificação das seleções, visualizar a tabela de artilharia e atualizar os placares por meio de uma API REST integrada a uma aplicação web.

## 📂 Estrutura do Projeto

```text
Copa-resultado/
├── backend/     # API REST (Express + Prisma)
├── frontend/    # Interface Web (React + Vite)
└── README.md
```

## 🚀 Como executar o projeto

Este projeto é dividido em duas aplicações independentes:

* **Backend** (API)
* **Frontend** (Interface Web)

Para executá-las, abra **dois terminais**.

### Terminal 1

Entre na pasta do backend:

```bash
cd backend
```

Em seguida, siga todas as instruções presentes no arquivo:

```text
backend/README.md
```

Lá você encontrará:

* Instalação das dependências
* Configuração do ambiente
* Banco de dados
* Como executar a API

---

### Terminal 2

Entre na pasta do frontend:

```bash
cd frontend
```

Depois siga as instruções do arquivo:

```text
frontend/README.md
```

Lá você encontrará:

* Instalação das dependências
* Configuração da aplicação
* Como iniciar o servidor de desenvolvimento
